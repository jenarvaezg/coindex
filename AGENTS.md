## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues using `gh`; external PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. See `docs/agents/domain.md`.
